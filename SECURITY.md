# Security Policy

## Purpose

This repository contains a proof-of-concept (PoC) for security research and educational purposes only. It is intended to help defenders, malware analysts, and researchers understand how App-Bound Encryption can be bypassed in memory by advanced infostealers, so that detection logic, mitigations, and forensic tooling can be improved.

## Reporting Misuse

If you believe this code is being used in a way that violates the intended research purpose, or if you have concerns about its impact, please open an issue in this repository. Reports are reviewed on a best-effort basis.

## Reporting Security Issues

This project does not ship a production service, so there is no supported deployment to report vulnerabilities against. If you find a bug in the PoC itself that affects its correctness or safety for research use, open an issue describing the problem.

## Scope

In scope:
- Bugs in the PoC implementation
- Documentation inaccuracies
- Requests for additional browser or architecture coverage

Out of scope:
- Assistance with using this code against systems you do not own or have explicit permission to test
- Requests for weaponized variants or data exfiltration functionality
